# Sebar Produk 1-Klik

Versi online-ready dari aplikasi Sebar Produk 1-Klik.

## Fungsi saat ini
- Simpan produk
- Tombol **SEBAR SEKARANG**
- Membuat 18 variasi konten untuk 6 kanal
- Tracking link dan pencatatan klik
- Pencatatan konversi/revenue
- Analytics API
- Export CSV
- Health check: /health
- Dockerfile untuk deployment

## Deploy ke blitz.cloud
1. Buka blitz.cloud dan login.
2. Hubungkan GitHub.
3. Pilih repository **sudarmin906/Sebarproduk**.
4. Pilih branch **main**.
5. Deploy menggunakan Dockerfile yang sudah tersedia.
6. Setelah build selesai, buka alamat HTTPS aplikasi.

## Penting
Versi ini sudah menjadi fondasi aplikasi online, tetapi **publikasi otomatis ke TikTok/Instagram/Facebook/YouTube/X belum diaktifkan**. Tahap berikutnya adalah OAuth/API resmi setiap platform dan provider AI server-side.

Jangan masukkan password, token, atau API key ke source code GitHub. Gunakan Environment Variables di hosting.
